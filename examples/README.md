# Examples

User-facing examples are grouped first by database dialect and then by application
domain:

- [`mysql/bookstore/`](./mysql/bookstore/) demonstrates a MySQL online bookstore.
- [`sqlite/field-journal/`](./sqlite/field-journal/) demonstrates a SQLite field
  journal backed by an existing file database.

Each project includes plain annotated SQL, its database schema, a
`sqlay.config.json`, and committed TypeScript generated by the real compiler. The
examples check recreates the required databases in temporary project copies,
compares generated output byte for byte, type-checks it, and runs the projects'
builder assertions without modifying these working directories.
